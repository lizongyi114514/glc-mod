# 绿灯军团 · Forge 1.20.1

把 `green-lantern-corps` 角色 Skill 的五维设定，做成 **Forge 模组**：七枚戒指、五种构念、电池誓词充能、七色被动、塞尼斯托 Boss。

- **Minecraft**：1.20.1
- **Forge**：47.x（开发时用 47.4.10）
- **Java**：17

---

## 1. 安装

把编译出的 `glc-1.0.0.jar` 放进 `.minecraft/mods/`，启动 Forge 1.20.1 即可。

> 联机时服务端也要装同一个 jar（模组注册了物品、方块与实体逻辑）。

---

## 1.5 开档设置：先选「被选中」还是「直接开始」

首次进入时聊天栏会给两个按钮：

| 选项 | 行为 |
|------|------|
| **被选中**（默认） | 不直接发戒指。后台观测你的行为，某色光关注度满 10 时，戒指从地平线飞过来，落地后才能捡。 |
| **直接开始** | 立刻发放绿灯戒指与电池，跳过等待。 |

**首次进入新世界时不需要任何指令**：模组会自动在出生点布置营地——

- 身前 3 格：欧阿传送门
- 身后 3 格：灯炉（3D 模型）+ 磁石台
- 聊天栏自动弹出上面两个开局选项（点击即可）

营地在每个存档只布置一次（全局标记 `#world_init`）。

也可以随时用命令切换：

```
/function glc:config/select_on
/function glc:config/select_off
```

### 行为观测规则（当前实现）

| 行为 | 吸引 | 增加值 |
|------|------|--------|
| 生命 ≤ 6 时击杀 | 绿灯（意志） | +3 |
| 夜间击杀（13000–23000） | 黄灯（恐惧） | +2 |
| 与村民完成交易 | 蓝灯（希望） | +2 |

关注度上限 10；达到后按 绿 → 黄 → 蓝 的顺序判定，只选中一次。
被选中后戒指会作为发光物品从 10 格外飞向玩家，落地方可拾取。

### 电影风格 3D 模型

戒指不再是平面贴图：`assets/glc/models/item/ring_*.json` 是 14 个 elements 的立体模型
（10 段银色环身绕 Z 轴旋转 + 宝石托座 + 方形祖母绿 + 两个镶爪），
参考 2011 电影版的银环方宝石结构；宝石贴图按七色单独生成。

### Strain（负担）与电量条

每次施放都会按当前 Strain 抬高本次电量消耗：

```
实际消耗 = 基础消耗 × (1 + Strain / 100)
```

- 施放后 3 秒内 Strain 不会回落，之后每秒 −2。
- Strain > 50 时，护盾和翼的持续时间减半（构造物加速消散）。
- 电量 ≤ 5% 时动作栏红字警告；归零后戒指熄灭，必须回灯炉念誓词。

HUD 现在是四条：`电量 87  负担 42  意志 64  Lv.3`。

### 意志力等级

- 击杀 +10 XP，升级所需 `20 × N × (N−1)`（2 级 40，3 级 120，4 级 240…）
- 被动：2 级抗性 I、6 级生命提升 I、11 级力量 I、17 级生命提升 II、20 级抗性 II

### 灯炉 / 磁石 / 誓词调谐

`/function glc:kit/start` 会同时在你脚下和电池底座中心放磁石。
充能仪式要求**站在磁石上**再潜行右键，否则提示「灯炉未调谐」。

## 1.8 欧阿（Oa）母星

数据包维度 `glc:oa`：虚空、末地风格天空、无怪物生成、固定正午。

| 步骤 | 操作 |
|------|------|
| 1 | 生存世界执行 `/function glc:oa/gate`，脚下立起 3×4 绿宝石传送门 |
| 2 | 站进门框中心，**潜行** → 传送到欧阿 |
| 3 | 广场中心是中央电池；北面是守护者大厅（四根石英柱 + 屋顶 + 海晶灯） |
| 4 | 电池下有 5×5 **磁石台**，站上去潜行右键即可调谐充能 |
| 5 | 南侧返回门，潜行回到你离开时的坐标 |

直接命令：`/function glc:oa/enter`、`/function glc:oa/leave`。

> 新维度需要**完全重启游戏**（不是 `/reload`）才会注册；首次进入会自动生成平台与大厅。

## 2. 获取戒指

| 方式 | 说明 |
|------|------|
| 创造模式 | 数据驱动版无法注册创造页签；用 `/function glc:kit/creative` 一次拿七色戒指 + 灯炉 |
| 合成 | 绿宝石块 ×8 + 钻石 ×1 → 信标（当作电池）；信标 + 4 个对应染料 → 该色戒指 |
| 命令 | `/function glc:kit/ring_yellow`（七色同理） |

> Java 源码里已有真正的创造页签 `ModCreativeTabs`（七色戒指 + 电池），编译后出现在创造物品栏，可直接搜索。

## 6. Boss

```
/glc boss
```

塞尼斯托：200 血、黄色皮革甲、铁剑；每 5 秒在最近玩家脚下召唤尖牙；半血召唤两名黄灯新兵（掠夺者）；
击杀后 64 格内玩家获得黄灯戒指与「最伟大的叛徒」进度。

## 7. 美术设计参考

**戒指（32×32）**：以 2011 电影版为骨架——银白金属环身 + 方形祖母绿宝石 + 四爪镶嵌；
内圈一道 1px 的意志光带来自动画版（*Green Lantern: The Animated Series*）的发光内环；
环身下方刻简化灯徽（两横一竖），对应漫画里戒指上的军团徽记。

**电池（3D 方块模型）**：参考漫画/动画里的个人提灯电源——深色金属底座与四角柱、四块绿色能量玻璃、
阶梯顶盖、顶部提手与灯徽，站在旁边有旋转的绿色粒子光环。

**动作**：施法时手臂挥动；五种构念各自有粒子形状（光束 / 球 / 弧 / 翼 / 抓取线）；
塞尼斯托身上每 0.5 秒一圈黄色恐惧光环。

预览图：`../glc-mod/docs/ring_sheet.png`、`../glc-mod/docs/battery_preview.png`。

## 8. 构建

需要 JDK 17 与 Gradle 8.8：

```bash
gradle build
# 输出 build/libs/glc-1.0.0.jar
```

本仓库的 `tools/` 里带了构建辅助：

- `tools/art.py`：生成 32×32 戒指贴图、提灯方块模型与贴图
- `tools/art_preview.py`：等轴测预览电池模型
- `tools/forge_proxy.py`：Forge maven 的本地缓存/固定 IP 代理（网络不稳时用）

`gradle.properties` 已配置：`GRADLE_USER_HOME` 指到项目内、代理指向 `127.0.0.1:8089`。
不需要代理时，删掉 `systemProp.*proxy*` 几行即可。

## 8.5 决斗（机制签名）

每个灯侠一套独立脚本，用命令开战：

| 命令 | 机制签名 |
|------|----------|
| `/function glc:duel/start_hal` | 幻翼高速绕飞，每 4 秒俯冲扫射一次；半血召唤「虚拟绿灯分身」继续骚扰 |
| `/function glc:duel/start_john` | 原地不动，每 5 秒垒一层阵地（胸墙→平台→顶盖），每层加抗性；每 3 秒射击一次 |
| `/function glc:duel/start_kyle` | 飞行 + 每 2 秒粒子爆发；每 5 秒切换形态（三种台词/粒子） |
| `/function glc:duel/start_guy` | 每 3 秒随机循环：巨锤（8 伤）/歪盾（吸收）/巨拳（挑飞） |
| `/function glc:duel/start_sinestro` | 不冲刺，每 0.3 秒向前一步；你拉开 6 格就被拽回；半血放黄光巨人 |
| `/function glc:duel/start_atro` | 受伤累积愤怒，力量等级随愤怒提升；近身持续灼烧 |
| `/function glc:duel/start_walker` | 不攻击，给其他决斗实体持续再生 + 抗性 |
| `/function glc:duel/start_larfleeze` | 每 8 秒召唤一个橙光复制体（僵尸 + 橙甲） |

所有决斗共用 `glc:duel` 血条；开新决斗会清掉上一场。普通灯侠、知名灯侠、决斗是三套独立系统。

> 模型仍是原版生物（幻翼/卫道士/劫掠兽/唤魔者/掠夺者）承载脚本，不是自定义实体模型。

## 10. 已知限制

- 戒指是 2D 物品贴图（Minecraft 物品模型限制），不是 3D 指环；手持时按原版物品展示。
- 塞尼斯托复用原版卫道士模型（黄皮甲 + 铁剑），没有自定义实体模型/动画。
- 誓词仪式为服务端计时 + 聊天播报，不要求玩家真的打字。
